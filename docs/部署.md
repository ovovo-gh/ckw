## 数据和权限

`backend/schema.sql` 创建 `public.chiikawa_records`（JSONB 记录和版本号）及私有图片桶 `chiikawa-private`。表开启 RLS，匿名和普通认证用户无表级读写权限；仅服务端角色可访问。存储桶不配置任何访客读取策略。

`space` 云函数使用服务端 API Key 访问 PG 和存储；管理员凭据必须只放云函数环境变量中。网站内两个账号由 scrypt 哈希验证，会话令牌仅在浏览器保存，云数据库保存其摘要。用户名密码不属于腾讯云登录账号。

所有数据读写经过 `backend/core.mjs`：访客数据投影排除价格和私人备注，私密记录不返回；图片每次读取都检查所属记录及当前可见性。设置公开时，图片可对访客显示，但私人字段继续隐藏。更新用条件版本写入，冲突返回 409。

网站走 HTTP 网关 `/api` 调用事件函数，不依赖浏览器 CloudBase SDK。匿名登录已关闭。`backend/gateway.rego` 仅追加放行 `/api` 的 POST 和 OPTIONS；其他资源权限保持平台默认值及 RLS 控制。不能把服务端 API Key 或密码哈希放入 `VITE_` 变量。

## 本地账号

```sh
npm run accounts
```

该命令只在账号文件不存在时生成两个随机测试账号，不覆盖已有账号。查看 `.local/测试账号.txt`；`.local/accounts.json` 包含盐和哈希。`.local/`、`.deploy/`、`.env.production.local` 全部被 Git 忽略。

更换密码时，用 `backend/core.mjs` 导出的 `makeAccount` 生成新盐和哈希，更新账号文件再部署后端。旧会话因密码哈希指纹改变自动失效。

## 重复发布

需要本机已登录 CloudBase CLI（本项目实际使用 3.8.4）和已保存的服务器凭据文件。服务器凭据文件为 `tcb env apikey create ... --json` 返回内容，仅保存到 `.local/cloudbase-backend-key.json`，不得提交仓库或输出日志。

项目根目录的 `.env.production.local`：

```dotenv
VITE_API_URL=https://gh-d0g7evem069de6a44-1497395816.ap-shanghai.app.tcloudbase.com/api
```

```sh
npm test
npm run build
CLOUDBASE_ENV=gh-d0g7evem069de6a44 npm run package:cloud
cd .deploy
npx @cloudbase/cli fn deploy space --force
npx @cloudbase/cli hosting deploy web -e gh-d0g7evem069de6a44
```

打包脚本将密码哈希以 Base64（不是加密）写入 `SPACE_ACCOUNTS_B64`，服务器凭据写入 `CLOUDBASE_APIKEY`。生成的 `.deploy/cloudbaserc.json` 是私密配置，权限为 600，不得分享或发布。运行环境 Nodejs20.19、内存 256 MB、超时 60 秒。

部署到其他环境时还需：执行 `backend/schema.sql`；用 `node scripts/seed-sql.mjs` 生成并执行 `.deploy/seed.sql`；创建 `/api` 到 `space` 的 HTTP 服务；应用网关策略；把网站域名加入安全名单，并修改 `backend/index.js` 的允许 Origin。初始条目以 `ON CONFLICT DO NOTHING` 写入，不覆盖用户修改和删除标记。

## 备份与存储清理

站点“导出备份”下载记录 JSON 和上传照片 ZIP，含私人信息，请妥善保存。图鉴和壁纸的预览与来源在 Git 仓库中。

删除为逻辑删除；孤立图片暂不自动回收。接近额度时先备份，再由管理员检查 `media` 对应记录是否已删除、图片是否仍被引用，只清理确认不用的对象。未保存的上传至少保留 24 小时后核对。不能直接删除 `storage.objects` 元数据，应通过 Storage API 删除对象。
