# chiikawa space

两个人共享的 Chiikawa 收藏室。React + Vite 前端；同一份后端逻辑支持本地持久化和腾讯 CloudBase 云函数、PostgreSQL 数据库、私有云存储。

## 功能

- 两个维护者账号；不开放注册，访客只能看公开内容。
- 收藏逐件增删改查、多张照片、人民币价格、私人备注、购买日期和渠道、类别、角色、到货状态。
- 私密收藏与照片由后端限制读取，价格与备注不返回给访客。
- 8 个系列、33 个官方来源的玩偶／毛绒挂件款式；可自行添加系列和款式。
- 想买清单；已到手的不同款式计入图鉴进度。
- 30 张官方来源壁纸预览：26 手机、4 横屏（电脑和平板可用）。精选原图按钮前往官方来源，自己上传的壁纸可直接下载原图。
- ZIP 备份包含记录、私人字段和上传照片；同时编辑时校验版本，防止静默覆盖。
- 手机、平板、电脑布局；页面不依赖外部字体或图片 CDN。

## 本地运行

使用 Node.js 20.19+（推荐 Node.js 22 LTS）。

```sh
npm ci
npm run accounts
npm run dev
```

打开终端显示的 `http://127.0.0.1:5173/`。首次生成的两位测试账号保存在 `.local/测试账号.txt`，哈希在 `.local/accounts.json`。这两个文件和上传内容都不会进入 Git。

本地数据保存在 `.local/data/`，刷新页面和重启服务不丢失。浏览器只保存登录令牌，不保存收藏数据。此地址只有本机可访问，不能直接发给另一台设备当作公网分享地址。

```sh
npm test
npm run build
npm start
```

生产构建的本地预览地址为 `http://127.0.0.1:8787/`。

## 图片与数据

- 商品图片和壁纸均保留原始来源，版权属于原作者／权利人。本项目不是官方站点。
- 图鉴是整理范围内的部分款式，不表示完整发行清单。中文名为整理译名。
- 现有官方壁纸来源主要为 X；网站内预览随站点托管，但外部原图来源在大陆可能无法直连。尚未取得站内原图再分发许可，因此未把全部原图镜像成公共下载。
- 用户上传收藏照片自动压缩到最长边 1600px；壁纸保留原始画质，免费测试版单张上传上限 3 MB，支持 JPG/PNG/WebP。HEIC 需先转格式。
- 删除是后端软删除，界面不提供恢复；数据库管理员可恢复。上传未保存及被移除的文件暂保留在私有存储，可按部署说明定期清理。

## 项目结构

```text
src/             前端与 HTTP API 通信层
backend/core.mjs  认证、权限、CRUD、图片与导出逻辑
backend/store.mjs 本地文件 / CloudBase 数据存储适配
backend/seed.json 官方来源的初始图鉴与壁纸预览数据
public/assets/   本地静态图片，不依赖境外图片 CDN
scripts/         本地账号、开发服务、云部署打包
tests/           隐私隔离、共享、版本冲突、持久化等回归测试
```
